# FrostyChat v8

Mobile-first P2P chat prototype using PeerJS.

Features: channels, message history, online members, typing indicator, replies, reactions, edit/delete own messages, image compression, image fullscreen/save, profile editing, notifications, emoji bar, responsive portrait UI and reconnect/error feedback.

Start a local/static web server or host the folder over HTTPS. Internet access is required for PeerJS signaling.
