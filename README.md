# FrostyChat v9

Temporärer P2P-Chat für Handy und Desktop.

- Nachrichten und Bilder werden nur während der laufenden Sitzung im Arbeitsspeicher gehalten.
- Keine Datenbank und keine dauerhafte Nachrichtenhistorie.
- PeerJS wird für die P2P-Verbindung verwendet.
- Die Web-App kann als PWA installiert werden.
